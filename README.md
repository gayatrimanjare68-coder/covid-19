
# 🌍 COVID-19 Global Data Analysis

## 📌 Overview

This project performs **Exploratory Data Analysis (EDA)** on a global COVID-19 dataset from Kaggle. It analyzes confirmed cases, deaths, recovery rates, weekly growth, and WHO region statistics across 187 countries.

## 🛠 Tools Used
* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
  

## 📊 Key Analysis
* 🔝 Top 10 countries by confirmed cases
* 📈 Countries with highest weekly growth
* ⚰️ Death rate per 100 confirmed cases
* 💚 Recovery rate distribution
* 🌍 Mortality comparison by WHO region
* 🔥 Correlation heatmap of numerical features


## 🚀 How to Run
pip install pandas numpy matplotlib seaborn
Open the notebook and run all cells.
